# 2026-09-28：发布 TalentBench 开源候选

状态：开源方向和产品边界已确认；公开仓库创建、首次推送及正式发布仍待负责人明确批准。

## 决策

负责人确认将个人拥有的本地招聘工作台整理为 **TalentBench 识才台**，以 **AGPL-3.0** 授权。此前“仅内部自用”与“禁止公开仓库”的限制，对经过剥离、审查和发布验证的本项目公开副本不再适用；这不构成公开任何原始资料、凭据或私有开发历史的许可。

公开仓库使用不带私有历史的干净初始提交。原应用仓库与其私有远端在准备过程中保持不动。

## 公开范围

保留本地岗位、JD、简历和截图人工校对、规则评级、测评归档、面试、人才库、备份恢复，以及用户主动配置和授权的可选外部 AI。飞书/Lark 妙记导入仍为有授权前提的可选联网能力。

删除招聘平台登录、只读同步、主动搜索及写类自动化，不提供自动联系、淘汰或录用。换用新名称和图标；内部数据标识按兼容需要保留。

## 首发与验证

当前为 1.0.1 公开版候选，未发布。Apple Silicon 采用本地候选包路线；未经公证的候选必须如实说明。Intel 仅源码未验收，Windows x64 实验性源码且首发无安装包，Windows 本机录音/ASR 禁用，Linux 未支持。

发布前完成干净安装、完整回归、公开内容与密钥扫描、依赖许可证核查、合成数据人工旅程和实际包验证。AI、麦克风及第三方服务的真实调用分别取得授权，不用模拟结果冒充真实验收。

## 未授权事项

本决策不直接授权创建公开仓库、推送、上传安装包或对外发布公告。发布负责人还需核对公开身份、私密安全报告渠道、发布内容和剩余限制，再明确批准。
