# 虚构岗位画像填写参考

用于“电商运营专员（虚构体验岗位）”。这是手工填写参考，不需要外部 AI。

先保存并启用 `01-虚构岗位JD.txt` 对应的 JD，再进入岗位画像表单，按同名字段填写：

**岗位职责**

整理商品信息、库存与促销活动安排。
用电子表格汇总运营数据，记录数据来源与计算口径。
协调设计、客服和仓储，跟进待办与活动复盘。

**必须条件**

能讲清自己参与的报表或运营活动，区分本人和团队的贡献。
能说明数据核对方法，避免把未经核实的信息作为结论。
能清晰记录问题、负责人和下一步。

**加分项**

有商品维护、库存协调或活动排期经验。
会使用数据透视表或常用查找函数。

**淘汰项**

留空。此处是 HR 人工判断提示，本次不填写自动决定去留的规则。

**测评报告策略**：选择“不要求”，本轮仅体验简历和手工流程。

**客观门槛**：学历、薪资和城市开关均保持关闭。

点击“保存岗位画像草稿”，在下方“版本记录”检查关联的 JD 和内容，再点击“确认此版本”。仅保存草稿不代表已确认。

两份样例资料都留有需要面试核实的内容，不预设 S/A/B/C 档位，也不预设录用或淘汰结论。
