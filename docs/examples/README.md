# 招才官：先用虚构材料体验

这里是一份最小样例包：一个虚构岗位、画像填写参考和两份 TXT 简历。所有姓名、机构、经历、薪资和项目均为人工编写，不对应真实招聘，不含真实电话、邮箱、账号或运行数据库。

| 材料 | 怎么使用 |
|---|---|
| [虚构岗位 JD](01-虚构岗位JD.txt) | 复制到岗位 JD 编辑区，不作为简历上传 |
| [岗位画像填写参考](02-岗位画像填写参考.md) | 按同名字段填写岗位画像 |
| [简历 01：示例林禾](resumes/简历01-示例林禾-完全虚构.txt) | 在当前虚构岗位中上传简历建档 |
| [简历 02：示例周宁](resumes/简历02-示例周宁-完全虚构.txt) | 在同一岗位中上传第二份简历 |

材料随源码放在 `docs/examples/`。保存简历时保留 `.txt` 扩展名及 UTF-8 编码，不要把网页另存为 HTML 后改名。

按[第一次使用](../GETTING_STARTED.md#first-use)操作：建立虚构岗位 → 保存并启用 JD → 保存并确认画像 → 上传 TXT → 核对后确认建档。这条体验路径不需要 AI 密钥、平台账号、PDF/OCR 工具或录音。

两份 TXT 已通过源码层面的文件校验、正文提取和结构解析检查；安装包中的完整操作与重启保存仍需验收。样例不会预先写入数据库，也不预设候选人档位或录用结论。

建议在独立试用环境中使用。已有业务数据时，不要为加载样例删除数据库、清空历史或替换数据目录。本最小包不包含截图或 PDF；截图是另一条需要人工校对并确认岗位归属的导入路径。
