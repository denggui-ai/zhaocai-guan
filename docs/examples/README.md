## 完成这三个动作

1. 新建“电商运营专员（虚构体验岗位）”；保存并启用 JD，按参考保存并确认画像。
2. 上传两份 TXT，分别核对姓名、岗位和原文，再确认建档。第一份确认后新增 1 人，第二份确认后共 2 人。
3. 打开两人的原始材料；正常退出并重开应用，选回虚构岗位，核对记录和材料仍在。

**完成标准：正确岗位下有 2 位候选人，原始材料能打开，正常退出重开后仍保留。** 如有差异，按[使用帮助](../GETTING_STARTED.md#help)检查，或通过中文 Issue 说明卡在哪一步。

## 材料与使用边界

所有姓名、机构、经历、薪资和项目均为虚构，不对应真实招聘，不含真实电话、邮箱、账号、运行数据库或密钥。材料不会自动载入或覆盖业务数据，不预设评级和录用结论。首次体验请使用单独的虚构岗位，不删除数据库、不清空历史。

两份 TXT 已有文件校验与正文/结构解析证据，合成材料的包内操作验收范围见[发行说明](https://github.com/denggui-ai/zhaocai-guan/releases/tag/v1.0.1-rc.1)；仍需在你自己的环境中核对上述结果。截图和 PDF 属于后续按需体验，不包含在此 ZIP。
