# 招才官 macOS 合成数据验收清单

适用于 1.0.1 公开版候选、Apple Silicon Mac 和隔离测试目录。当前尚未发布；首轮结论上限为 `GO WITH CONDITIONS`，不表示公证、生产使用或真实材料准确率达标。

## 准备

- [ ] 核对候选版本、源码 commit、包 SHA-256 和构建证据。
- [ ] 只准备虚构岗位、合成 PDF/Word/TXT 和明确标注虚构的详情截图，不使用真实候选人资料。源码包的 `docs/examples/` 提供岗位、画像和两份 TXT，样例包本身不含图/PDF。
- [ ] 使用独立测试数据目录；外部 AI 关闭，不使用真实账号、密钥或面试录音。
- [ ] 记录测试人、设备、系统和开始时间；所附截图不得含个人资料。

## 操作

1. 建岗，保存 JD 草稿后在版本记录中启用；保存岗位画像草稿后确认对应版本。关闭并重新进入，核对状态和内容持久化。
2. 在独立虚构岗位导入两份 TXT，先取消第一份确认窗口并核对人数仍为 0，再分别确认建档，核对人数从 1 到 2。检查字段、多段经历与原始证据；人工修改后再次打开。简历确认不得自动评级或调用 AI。
3. 导入合成截图，核对任务输入、处理、草稿、待校对和失败计数；确认草稿的岗位归属，必要时手动切换专用截图岗位，不将当前岗位未变化误判为导入丢失。
4. 确认前不得出现正式候选人；对照原图修正姓名后确认一份，驳回另一份。
5. 核对正式候选人和规则评级只包含已确认材料，跨岗位切换不串数据。
6. 测评 PDF 缺依赖时应有明确提示；依赖齐全后验证预览与归档。
7. 正常退出、重新启动，核对岗位、材料与任务恢复；检查退出后无应用服务残留。

## 停止与恢复

发现未批准外发、错误合并、跨岗位访问、证据丢失或数据库异常时停止，保留合成复现和首个错误。不使用唯一业务数据做降级实验。

回滚前完全退出应用，保存**整个数据目录**，包括数据库 sidecar、材料、任务与审计记录；需要回退时恢复匹配版本及完整目录，不能只替换数据库主文件。

## 记录

写明完成步骤、首个失败动作、原始错误及证据位置。技术结果使用 PASS / FAIL / BLOCKED；另列未测范围。麦克风、外部 AI、复杂真实版式、Intel 和 Windows 都需要独立验收，不能由本清单推断通过。

首版允许未公证的 Apple Silicon 包，但本清单及自动自检均不授权公开分发。负责人须核对最终包的版本、提交、校验和、人工业务与安装验收记录，明确接受或阻止发布，并记录未验证能力、依赖和升级限制。发布说明须保留未公证状态及安装放行方法；Developer ID 与公证留待后续渠道，不将其缺失自动判为本次首发失败。
